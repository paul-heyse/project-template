# Library overviews

Optional, repository-agnostic capability overviews help identify useful library features before
consulting Context7, current primary documentation, GitHub or installed sources for consequential
details. They provide orientation; adoption decisions belong with the relevant design work.

Use the [authoring guide](authoring-guide.md) when producing an overview. Add links here as overviews
become available; this index and authored overviews belong to the project.

For a deliberate codebase-first inquiry, use the separate
[library-leverage workflow](../library_leverage/README.md). Its three skills identify concrete
opportunities, assess focused capability applicability and compare complete options. Useful
library types and additional patterns persist after current codebase matches retire.
